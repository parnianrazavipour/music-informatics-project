# music-informatics-project

We propose using the Ballroom dataset (we may change the dataset if we find something better), which contains 698 of 30 second excerpts across eight dance styles such as Cha Cha, Tango, and Waltz along with tempo annotations, providing a compact and manageable benchmark for our investigation. Our core investigation examines whether an audio classifier genuinely learns stylistic rhythmic patterns or merely exploits playback speed as a shortcut, given that each genre has a characteristic tempo range that models can use to inflate performance. To test this, we will train classifiers using timbral features (MFCCs, zero-crossing rate, and spectral centroid), rhythmic features derived from tempograms (cyclic tempograms, autocorrelation tempograms across tactus and measure levels, and predominant local pulse (PLP)), and a tempo-only baseline to quantify the predictive power of speed alone (we may add more features if we want to). Because the dataset lacks a standardized benchmark split, we will evaluate these configurations using stratified 5-fold cross-validation. We will then assess model robustness by time-stretching the test audio by ±2%, ±5%, and ±10%, modifying the tempo while leaving the musical style intact; the ±2% condition acts as an experimental control to confirm that any performance decline stems from the tempo shift rather than signal processing artifacts. By evaluating classification accuracy against stretch magnitude and F1 scores for each feature set, and together with analyzing the confusion matrices, a sharp drop in accuracy would reveal that the models rely predominantly on tempo cues rather than substantive genre features.
